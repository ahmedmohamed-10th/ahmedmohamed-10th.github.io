Terminal and Vim Guide

A guide to the Terminal and Vim commands we learned in class.

Terminal

The Terminal lets you interact with your computer by typing commands.

  • pwd - Shows your current directory.
  • ls - Lists files and folders.
  • cd - Changes directories.
  • mkdir - Creates a new directory.
  • rm - Removes a file.
  • cp - Copies a file.
  • mv - Moves or renames a file.
  • grep - Searches for text.
  • less - Lets you read a file.

Vim

Vim is a text editor that can be used from the Terminal.

How to Use Vim

  1. Open a file with vim filename.html.
  2. Press i to enter Insert Mode.
  3. Type or edit your text.
  4. Press Esc to return to Normal Mode.
  5. Type :w and press Enter to save.
  6. Type :q and press Enter to quit.

Useful Vim Commands

  • i - Insert Mode
  • Esc - Normal Mode
  • :w - Save
  • :q - Quit
  • :wq - Save and quit
  • :q! - Quit without saving

Tips

  • Use pwd to see where you are.
  • Use ls to see your files.
  • Press Esc before using Vim commands like :w.
  • Remember that Vim has different modes.
